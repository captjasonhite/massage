# Guided Massage

**A step-by-step, 60-minute full-body massage session that runs on any phone.**

🔗 **Live:** [captjasonhite.github.io/massage](https://captjasonhite.github.io/massage/)

<img src="docs/start.png" width="260" alt="Guided massage start screen">

## Features

- 30 minutes face-down, 30 minutes face-up, broken into timed segments by body area
- A diagram and instructions for each step, with a countdown and overall progress
- Optional voice guide, chimes and vibration, so you can keep your eyes off the screen
- Keeps the screen awake during a session; installs to the home screen and works offline once loaded
- No sign-up, no tracking of personal data
